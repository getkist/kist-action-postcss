# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.23] - 2026-08-01

### Changed

- Updated dependencies
- `engines.node` is now `>=22.0.0`

## [1.0.0] - 2025-02-08

### Added

- Initial release
- `PostCssAction` for CSS processing with PostCSS
- Autoprefixer integration for vendor prefixes
- cssnano integration for CSS minification
- Sourcemap generation (inline and external)
- Support for custom PostCSS plugins
- Configurable browser targets
- TypeScript support with full type definitions
